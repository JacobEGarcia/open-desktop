# OPEN desktop

A self-contained, client-side personal desktop prototype inspired by Chris Tate's open-desktop demo. Open `index.html` directly or serve the folder as static files. Nothing to install. No AI or OS integration is claimed.

Commands: `open notes`, `create note Weekend ideas`, `find ideas`, `save file draft.txt: Hello`, `calculate 12 * 7`, `search web for typography`. Use the four shortcuts for direct access. Notes and text files save to the browser's localStorage; importing accepts small text files only. Browser links open in a separate tab. The pin button persists a view choice. Cmd/Ctrl+K focuses the command line, Escape closes a panel. This is a free web app, not a Debian distribution, model inference, remote machine, or cross-device sync.

The demo video is at https://x.com/ctatedev/status/2103517099511451940 . Its coast footage is not shipped. The background in this app is a separate public-domain NOAA photograph by Michael Theberge from https://commons.wikimedia.org/wiki/File:Sea_Stacks_on_Oregon_Coast.jpg .
